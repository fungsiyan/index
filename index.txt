• Hosting (Docker):**
```
docker pull xtjoeytx/gserver-v2:latest
docker run -d -p 14900:14900 xtjoeytx/gserver-v2:latest \
    --server default \
    --port 14900 \
    --localip <lan-ip> \
    --serverip <external-ip-or-hostname> \
    --interface 0.0.0.0 \
    --name <server-name> \
    --staff <account-name>
```
